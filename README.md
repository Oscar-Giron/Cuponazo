Cuponazo es una plataforma web de tipo E-commerce diseñada para que los usuarios puedan adquirir actividades y servicios a precios económicos mediante el uso de cupones. Este proyecto sigue una arquitectura clásica de cliente-servidor con un modelo de tres capas.
Roles del Sistema
El sistema diferencia entre dos tipos de actores principales:
Usuario estándar: Puede registrarse, consultar el catálogo, gestionar su perfil, realizar compras y canjear cupones.
Administrador: Encargado de gestionar usuarios, supervisar datos, acceder a estadísticas, gestionar el catálogo (CRUD de productos) y revisar los logs del sistema.

Arquitectura y Diseño
La aplicación está estructurada en tres niveles para garantizar modularidad y mantenimiento:
Capa de Presentación: Interfaz intuitiva y accesible donde se muestra el catálogo y el carrito.
Capa de Negocio: Procesa la lógica (validación de credenciales, cálculo de precios, gestión de stock).
Capa de Datos: Almacenamiento estructurado en tablas como Usuario, Cupón, Compra y Pago.
Identidad Visual
El diseño se centra en la claridad y la usabilidad:
Paleta de colores: Verde Esmeralda (#16A34A) para acciones principales, Gris (#4B5563) para textos secundarios y Azul Oscuro (#1E293B) para títulos.
Logo: Un ticket con el nombre "Cuponazo" y una tira lateral que simula el corte al canjearse.
